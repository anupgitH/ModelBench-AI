# 🤖 ModelBench AI

### Automated Machine Learning Training & Evaluation

ModelBench AI is an interactive machine learning workspace built with Python and Streamlit. It enables users to upload datasets, train classification models, compare their performance, generate predictions, and save trained models and evaluation reports.

## ✨ Features

- 📂 Upload CSV datasets
- 📊 Explore dataset statistics and preview data
- ⚙️ Configure machine learning experiments
- 🎯 Select the target column
- 🧠 Train multiple classification models
- 📈 Compare model performance
- 🔍 Visualize confusion matrices
- ⭐ Analyze feature importance
- 🔮 Generate manual predictions
- 💾 Save trained models and metadata
- 📥 Export evaluation reports and comparison results

## 🛠️ Tech Stack

- **Language:** Python
- **Web Framework:** Streamlit
- **Data Processing:** Pandas
- **Machine Learning:** Scikit-learn
- **Visualization:** Matplotlib
- **Model Serialization:** Joblib

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or later
- Git
- pip

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/ModelBench-AI.git
cd ModelBench-AI
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a Virtual Environment

**macOS / Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal, usually:

`http://localhost:8501`

## 📁 Project Structure


The `models/` and `reports/` directories store trained model artifacts and evaluation reports generated by the application.

## 🔄 Workflow

1. Upload a CSV dataset.
2. Review dataset statistics and preview the data.
3. Select the target column.
4. Configure the test dataset percentage and random seed.
5. Select the classification models to train.
6. Train and evaluate the selected models.
7. Compare performance metrics and visualizations.
8. Generate predictions and save available artifacts.

## 📊 Evaluation Metrics

Depending on the implemented evaluation workflow, the application can display:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
